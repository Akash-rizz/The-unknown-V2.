# THE UNKNOWN // MULTIVERSE

A multi-page cinematic science website.

Files:
- index.html — Home
- universe.html — Universe
- quantum.html — Quantum
- life.html — Life Engine
- ai.html — AI Core
- experiments.html — Experiment Lab
- unknown.html — The Unknown
- style.css — Shared visual system
- script.js — Shared interactions, page transitions, starfield and lab control

GitHub Pages:
1. Create a PUBLIC repository.
2. Upload all files to the repository root.
3. Settings → Pages → Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save.

Important: Keep `script.js` named exactly `script.js`.
The site uses Google Fonts and no external image files. The starfield and effects are generated in CSS/JavaScript.
